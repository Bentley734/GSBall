# Changelog

## [1.1.0] - 2026-10-21

### Added
- Gold and Silver support through a quest adaptation: Goldenrod receptionist delivery, Kurt's next-day investigation, and a real level 30 Celebi battle at the Ilex Forest shrine.
- Protected GS Ball key item using unused Gold/Silver slot $73.
- Saved quest stages, full-pocket recovery, native apricorn priority, and shrine retries after fleeing, fainting Celebi, or whiteout.
- Integration coverage with both games' imported maps and native world/script/inventory/battle construction on engines 0.3.54 and 0.3.58.

### Preserved
- Elite Four and Lance victory requirement for all three games.
- Crystal's existing native event activation and scripts.

## [1.0.0] - 2026-10-21

### Added
- Crystal-only activation of the native GS Ball receptionist event after the first Elite Four and Lance victory.
- Support for new games, loaded saves and campaign arrivals.
- Preserve existing activation and quest progress; leave native scripts in control.
